An alien tourist's one-line review of Earth, at most 200 characters, for the
[make.fun competition](https://make.fun/c/u-swift-raven-16-alien-field-notes-the-two-day-earth-7647b000).

The entry (123 characters):

> Earth: the locals pay strangers to shout at them while they lift heavy objects for fun. 5 stars, would get yelled at again.

## How to run

`main.py` (stdlib only) copies `entry.txt` byte-identically to
`$MAKEFUN_OUTPUT_DIR/entry.txt` with mode 0644, without temp files:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/output python3 main.py
```
